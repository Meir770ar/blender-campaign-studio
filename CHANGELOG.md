# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-23

First public release of the skill as used in production by the author since 2026-09-06.

### Added
- Interview, brief, direction and shot contracts with staged creative gates (direction, styleframes, paid motion, rough cut).
- Provider job ledgers: prepare, approve, execute once, collect; batch approvals with a shared cap and a pilot; Suno clip extension; positive style constraints with a short exclusion list folded into every prompt.
- Narration script with directed pauses rendered as one ElevenLabs request and cut by word timestamps; per-segment mode for retakes.
- Sound finishing: stems, speech-driven ducking, per-track gain envelopes, two-pass loudness, Foley event contracts, edit audits, delivery QA bound to the mix targets.
- Hebrew typography rendered by Chromium with licensed fonts; captions with spoken-word emphasis and brand-colored words; Tesseract kinetic titles.
- Blender 5.1 assembly from Timeline JSON v1: motion presets, transform keyframes, image sequences with alpha, freeze frames; product stage, camera projection, planar screen replacement and a controlled product reveal.
- DaVinci Resolve Studio hand-off (FCP7 XML, verified import, unmapped-feature report), remote Cycles rendering and a verified production archive on a GPU station.
- Grok Imagine Video 1.5 through an OpenClaw gateway (with the native provider patch package), Genspark, Magnific/Dzine and HeyGen routes; Gemini-based script writing, shot/master analysis and closed-question vision checks.
- Compressed viewing copies and optional WhatsApp self-delivery with a receipt ledger.
- Character sheet, narration and long-form mix templates; a complete recipe for a 150-second commercial.
