# הפעלת הרחבת Grok במנוע הקיים

התיקון מוכן מקומית ומיועד ל־OpenClaw 2026.7.1 בשער ההפקה הקיים.
הבדיקה המקומית משחזרת את ההנמכה מ־1080p ל־720p בקוד המקורי ומאמתת שהקוד המתוקן משמר 1080p.

ההפעלה משנה שני קבצים בלבד בקונטיינר `<openclaw-gateway-container>`:

- `/app/extensions/xai/video-generation-provider.ts`
- `/app/dist/video-generation-provider-PMWf4yep.js`

הפעלה מחייבת אישור מפורש לשינוי בשרת ולאתחול קצר של שער OpenClaw. האתחול משפיע על השירות שבקונטיינר כולו.
לא משתנים חשבון, הרשאות OAuth, טיפול ברענון ההתחברות, מודל ברירת המחדל של סוכנים אחרים או מפתחות API.
לא נשלחת בקשת יצירה בעת ההפעלה.

הקוד מוסיף את `grok-imagine-video-1.5`, 1080p ביצירה מטקסט/פריים ראשון יחיד, שליטה באודיו, עד שבעה רפרנסים ופריים ראשון/אחרון, עריכה והארכה. שילובים שאינם נתמכים נדחים לפני גישה לספק. מסלולי רפרנסים ופריים אחרון מוגבלים ל־720p; עריכה והארכה יורשות את פורמט המקור.

תצוגה מקדימה:

```powershell
python scripts/activate_grok_patch.py
```

לאחר אישור להפעלה ולאתחול:

```powershell
python scripts/activate_grok_patch.py --apply --approval-evidence "האישור המדויק מהמשימה הנוכחית"
python scripts/provider_jobs.py probe grok
```

הסקריפט מאמת SHA-256 של שני קבצי היעד מול הגיבוי לפני כל שינוי ושומר קבלה מקומית. אם הקוד בשרת השתנה בינתיים, ההפעלה נעצרת. שחזור משתמש באותם קבצים ובאימות הפוך:

```powershell
python scripts/activate_grok_patch.py --rollback --apply --approval-evidence "אישור השחזור והאתחול"
```

החלפת קונטיינר או שדרוג OpenClaw עשויים להסיר את התיקון. בדיקת ההפקה מאמתת את סימון החוזה ואת היכולות לפני יצירה ועוצרת במקרה כזה. אין להתקין את החבילה על גרסה אחרת ללא התאמה ובדיקה.

בדיקות מקומיות אינן הוכחה שהמנוי יקבל כל בקשת מודל. ניסוי יצירה מחייב אישור נפרד לצריכת המכסה; יש לבדוק את קובץ הפלט, הסנכרון והתנועה לפני הרחבת ההפקה.
