# Tutorials into reproducible techniques

Research only what the brief or requested library expansion needs. Prefer creator-owned tutorials, Blender Studio and official docs. Find actual video/project sources, not reposted course downloads.

Inspect relevant frames or a legitimately available transcript and project materials. A title/snippet permits shortlisting, not a claim that a method was learned or tested. Record URL, creator, chapter/timecode and Blender/add-on versions. Label inaccessible content and use an accessible source instead of inventing steps.

Create an original minimal Blender implementation with useful parameters. Confirm asset/add-on permissions before incorporation. Each accepted technique includes:
- technique.md describing effect, narrative use, controls, source, permissions/dependencies, tested version and limitations;
- working script or reusable .blend scene/node group;
- small preview with measured render time and hardware;
- normal and relevant boundary inputs (long Hebrew title, narrow aspect, timing extremes).

Mark verified only after it renders, varies without breaking and passes visual inspection. Begin with pilot requirements: product lighting, controlled reveal, masked typography or a logo reveal. Estimate simulation-heavy effects separately.

Research starting points, not validated recipes:
- https://studio.blender.org/training/geometry-nodes-from-scratch/
- https://studio.blender.org/training/motion-graphics/
- https://www.youtube.com/watch?v=factEb5ZaxM

Check instructions against the installed API and rerender after a version migration.
